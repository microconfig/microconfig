# Оптимизация холодного запуска CLI

Замеры выполнены 2026-11-07 после отключения энергосбережения.
`pmset -g custom` подтвердил `AC Power`, `lowpowermode 0`.
Время первой серии из `results.json` не используется для оценки ускорения кода:
в той серии режим питания был другим.

| --- | ---: | ---: | ---: | ---: |
| Опубликованная 4.9.7 | 7 | 299.8 мс | 289.6–331.0 мс | 219.8 MiB |
| 5.0.0 после оптимизации | 7 | 402.8 мс | 391.2–408.2 мс | 189.4 MiB |
| 5.0.0 до оптимизации, повторный замер | 3 | 1144.8 мс | 1141.0–1157.9 мс | 475.0 MiB |

Текущая версия на 34.4% медленнее 4.9.7
(разница 103.1 мс).
Равенство по скорости пока не достигнуто. Относительно исходной 5.0.0 при том же
режиме питания время сократилось в 2.84 раза;
пиковый RSS — с 475.0 до 189.4 MiB.
В контрольной серии исходной 5.0.0 медиана 4.9.7 составляла
308.5 мс.

Каждый запуск — отдельная холодная JVM, без прогрева, дополнительных JVM-флагов
и профайлера. Старый и новый JAR запускаются попеременно, каждый раз в новый
пустой каталог. Использованы тот же репозиторий на 50 компонентов с include
глубиной 3 и один OpenJDK 25.0.2. Кеш ОС не сбрасывается.
Во всех семи итоговых парах и трёх контрольных парах **100 выходных файлов
совпали побайтово**. Они содержат 8850 свойств, как в исходном бенчмарке.
Это проверка данного набора конфигураций, а не доказательство совместимости
со всеми возможными репозиториями.

## Что изменено

- `FilePropertiesRepository` сохраняет разобранный `RawConfig` на одну сборку.
  Ключ включает файл, окружение и тип конфига. Кешируется исходный разбор;
  обход include и его приоритеты вычисляются для каждого корня отдельно.
  Базовые свойства без overrides индексируются один раз; возвращаемые карты
  отделены от кеша.
- `StandardResolveStrategy` переиспользует неразрешённые наборы свойств по
  компоненту, окружению и типу. Это убирает повторное создание и индексирование
  `TypedProperties` на каждую ссылку. Значения выражений этим кешем не сохраняются.
- В кеше списка файлов каталога проверка `isFile` выполняется при создании
  снимка, а не при каждом запросе типа или окружения.
- YAML-дерево переиспользует parser в пределах одной сериализации. Для
  консервативного подмножества простых значений тип определяет штатный
  `SnakeYAML Resolver`; сложный синтаксис проходит полный parser. Узлы создаются
  отдельно, поэтому одинаковые ключи не превращаются в искусственные anchors.
- Убраны лишний цикл parse/emit перед записью, разбор простых констант и
  маскировка целых ссылок при разрешении YAML. Поиск пользовательских statements
  продолжает выполняться. Разбор YAML одновременно сохраняет события для
  комментариев и явных тегов, без второго сканирования документа.
- При индексировании чистого YAML не создаётся дополнительная карта для
  идентичности Properties-ключей. Смешанные форматы сохраняют прежнюю обработку.
- Обычный путь вывода разрешается через ближайший существующий префикс;
  пути с `.`/`..`, dangling и циклическими symlink сохраняют прежний обход.
  Не строятся таблицы для отсутствующих шаблонов и не выполняется лишняя
  работа с отсутствующими предыдущими/устаревшими конфигами.
- Преобразование простых результатов SpEL в строки обходится без инициализации
  общего набора конвертеров. Для остальных типов используется прежний
  `StandardTypeConverter`, включая коллекции, массивы и null.

Все кеши данных создаются внутри зависимостей одного `Microconfig` и исчезают
вместе с ним. Общий `SnakeYAML Resolver` содержит неизменяемые правила схемы,
без файлов, YAML-узлов или состояния сборки. `CacheProxy` не возвращался.

## Проверки

`./gradlew --offline test :microconfig-cli:shadowJar` — **2202 теста,
0 ошибок, 0 пропусков**. `git diff --check` прошёл.
Добавлены проверки повторного разбора общих include, контекста обхода разных
корней, окружений и типов одного файла, обновления следующей сборки, защиты
кешированной карты от изменений, YAML-типов и независимости anchors,
пользовательского resolver, отложенного удаления diff и результатов SpEL.
Общий набор также проверяет смешанные форматы, профили, алиасы, шаблоны,
коллизии и symlink, Java API и динамические выражения.

## Воспроизведение

```sh
./gradlew --offline :microconfig-cli:shadowJar
python3 benchmarks/cache-comparison/run.py \
  --old-jar /path/to/microconfig-cli-4.9.7.jar \
  --new-jar microconfig-cli/build/libs/microconfig-cli-5.0.0.jar \
  --java /path/to/java \
  --runs 7 \
  --results benchmarks/cache-comparison/work/repeat-optimized.json
```
